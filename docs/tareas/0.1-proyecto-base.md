# 0.1 Proyecto base
Objetivo: dejar un proyecto Next.js que corre y tiene sus chequeos configurados.
Plan: Fase 0, tarea 0.1.
Pasos:
1. Generar Next.js (App Router, TypeScript, Tailwind, ESLint, `src/`, alias `@/*`) con pnpm.
2. TypeScript con `strict: true` y `noUncheckedIndexedAccess`.
3. Configurar Prettier, con `eslint-config-prettier` y el plugin de Tailwind.
4. Configurar Vitest con una prueba inicial sobre `src/ui/textos.ts`.
5. Configurar Playwright con Chromium y viewport de celular, en `tests/e2e/`.
6. Escribir la prueba e2e, verla fallar y crear una página mínima con textos en `src/ui/textos.ts`.
7. Agregar scripts: `dev`, `build`, `lint`, `typecheck`, `test`, `test:e2e`, `format`.
Lista cuando:
- `pnpm dev` muestra una página en español con textos desde `src/ui/textos.ts`.
- `pnpm lint`, `pnpm typecheck`, `pnpm test` y `pnpm test:e2e` pasan.
- `tsconfig` tiene `strict: true`.
- `.gitignore` excluye `.env*`.
Fuera de alcance: Supabase, fechas, CI, hooks, Zod y pantallas del producto.
