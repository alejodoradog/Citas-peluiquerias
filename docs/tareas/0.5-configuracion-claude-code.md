# 0.5 Configuración de Claude Code
Objetivo: convertir las reglas del proyecto en configuración que se cumple sola.
Plan: Fase 0, tarea 0.5, y sección "Configurar Claude Code".
Pasos:
1. Reglas en `.claude/rules/` para migraciones y `src/app`.
2. Skills `nueva-migracion`, `nueva-pantalla` y `cerrar-tarea`.
3. Subagentes `revisor-spec` y `revisor-seguridad`.
4. Hooks: Prettier y ESLint tras editar; typecheck y pruebas afectadas en `Stop`; bloqueo de `.env*` y de comandos contra producción.
5. MCP: Supabase local, Playwright y GitHub con token en variable de entorno.
6. Actualizar `CLAUDE.md`.
Lista cuando:
- Los hooks se prueban disparando de verdad.
- Los subagentes y skills aparecen tras recargar.
- `claude mcp list` muestra el estado real de cada servidor.
- Lint, typecheck y pruebas pasan.
Fuera de alcance: las reglas de negocio.
Requiere del dueño del proyecto: crear el token de GitHub limitado a este repo y guardarlo como variable de entorno.
