# 1.10 Infraestructura base
Estado: pendiente; requiere aprobar la decisión 0007.
Objetivo: comprobar que la app actual corre en Cloudflare Workers con OpenNext, y dejar las vistas previas por PR en Cloudflare. Si no funciona, quedarse en Vercel Pro con la razón documentada.
Decisión: `docs/decisiones/0007-infraestructura.md`.
Puede ir en paralelo con la 1.9, porque no toca la base de datos. Las dos deben estar listas antes de la fase 2.
Requiere del fundador: crear la cuenta de Cloudflare, el token de API y el `CLOUDFLARE_ACCOUNT_ID` en los secretos de GitHub.
Pasos:
1. Agregar `@opennextjs/cloudflare`, `wrangler.jsonc` y `open-next.config.ts`, con versiones fijas.
2. Construir en CI (Linux) con OpenNext y anotar el tamaño del Worker.
3. Resolver la sesión sin el middleware de Node, probando en este orden:
   - `proxy.ts` tal cual;
   - `middleware.ts` en el runtime edge;
   - refrescar la sesión dentro de las páginas y acciones.
4. Correr las pruebas e2e contra el Worker local (`opennextjs-cloudflare preview`) con Supabase local.
5. Subir una versión de vista previa por PR desde GitHub Actions, apuntando a `barberias-dev`, y dejar su URL en el PR.
6. Medir:
   - el CPU por petición (p50 y p95) en `/`, `/ingresar` y `/panel`;
   - la latencia desde Colombia hasta `us-east-1` y `sa-east-1`.
7. Confirmar qué SDK de Sentry funciona con OpenNext, y el costo del tag cache si se usa revalidación por etiquetas.
8. Actualizar `CLAUDE.md` (stack y comandos), `docs/plan.md`, la tabla de ambientes y `docs/operacion/configurar-barberias-dev.md` con el resultado.
Lista cuando:
- El build de OpenNext pasa en CI y el Worker cabe en el límite.
- Las 16 pruebas e2e pasan contra el Worker local.
- Cada PR tiene una vista previa en Cloudflare que funciona con `barberias-dev`: registro, confirmación de correo e ingreso.
- Las mediciones quedan anotadas en esta tarea, con la región recomendada.
- O bien: se documenta qué falló, y la decisión 0007 queda con Vercel Pro.
Criterio para abandonar: si los pasos 3 o 4 no pasan tras un día de trabajo, se pasa al plan B.
Fuera de alcance: producción, dominio, R2, SES y Turnstile, que llegan en las tareas de la tabla "Plan de adopción" de la decisión 0007.
