# 0.2 Supabase local
Objetivo: Supabase corriendo en local, con clientes tipados para servidor y navegador.
Plan: Fase 0, tarea 0.2.
Pasos:
1. Instalar Supabase CLI y correr `supabase init`.
2. Crear los clientes de servidor y navegador en `src/lib`.
3. Agregar un script para generar tipos.
Lista cuando:
- `supabase start` y `supabase db reset` funcionan.
- Los tipos se generan con un solo comando.
- La clave de servicio no puede llegar al navegador.
- Lint, typecheck y pruebas pasan.
Fuera de alcance: las 11 tablas (fase 1), RLS y Auth.
Preguntas abiertas:
- `CLAUDE.md` prohíbe leer y escribir `.env*`, pero los clientes necesitan URL y claves. ¿El dueño del proyecto crea `.env.local`? ¿Se puede crear un `.env.example` sin valores?
- Docker Desktop debe estar encendido.
